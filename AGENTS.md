# AGENTS.md

## Project

This is a tiny single-file Python coding-agent experiment.

## Commands

- Run: `python3 agent.py`
- Syntax check: `python3 -m py_compile agent.py`

## Coding Guidelines

- Keep the implementation simple and readable.
- Prefer Python standard library only unless explicitly asked otherwise.
- Prefer exact, minimal edits over large rewrites.
- Keep terminal output readable and concise.

## Agent Behavior

- Inspect files before editing them.
- Show file paths clearly.
- Do not claim a tool or file change succeeded unless it actually did.
